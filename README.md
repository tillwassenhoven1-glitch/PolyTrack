# 🏎️ Poly Rush 3D

Ein Low-Poly-Rennspiel im Browser: Rase über Strecken mit Loopings, Wandfahrten, Steilkurven, Sprüngen und scharfen Kurven – gegen die Uhr, auf die Millisekunde genau. Schlag deine eigenen Geister und bau dir im Editor eigene Strecken!

## So funktioniert's

- 🚦 Nach dem Countdown 3-2-1 geht's los – die Zeit läuft auf die Millisekunde genau
- 🟡 Fahr durch **alle Checkpoints**, sonst zählt das Ziel nicht
- ⏱️ An jedem Checkpoint siehst du deine Zwischenzeit – **blau** = schneller als deine Bestzeit, **rot** = langsamer
- 📍 Von der Strecke gefallen? Du startest automatisch am letzten Checkpoint neu
- 🏁 Im Ziel landet deine Zeit in der Bestenliste – und als Geist für das nächste Rennen

## Features

- 👻 Fahr gegen **bis zu 10 Geister** gleichzeitig – deine besten Läufe als durchsichtige Autos
- 👁️ Wiederholungen: Schau dir deine besten Läufe nochmal an
- 🏆 Bestenliste (Top 10) für jede Strecke, mit Spielername und Datum
- 🔥 Driften mit Reifenrauch
- 🛠️ **Strecken-Editor** mit 30 Bauteilen – bauen, testen, speichern
- 📤 Strecken als Code **exportieren** und mit Freunden **teilen** – 📥 importieren mit einem Klick
- 🎨 **Garage**: Lackfarbe, Zweitfarbe, 5 Lackmuster und 4 Felgen-Designs
- 🎥 4 Kamera-Perspektiven (Verfolger, Weit, Motorhaube, Ego-Sicht)
- 🌗 Echtzeit-Schatten und einstellbarer Sonnenstand
- ⌨️ Frei belegbare Tasten (2 pro Aktion)
- 🎮 Gamepad-Unterstützung (X / RB zum Driften)
- 🔊 Motor-Sound, Checkpoint- und Ziel-Sounds
- 📲 Touch-Steuerung fürs Handy/iPad
- 💾 Zeiten, Geister, Strecken und Auto werden in deinem Browser gespeichert
- 🚫 Komplett kostenlos – keine Werbung, keine Abos

## Steuerung

| Aktion | PC | Handy / iPad |
|---|---|---|
| Gas | W / ↑ | ▲ |
| Bremsen / Rückwärts | S / ↓ | ▼ |
| Lenken | A / D oder ← / → | ◀ ▶ |
| Driften | Leertaste / Shift links | DRIFT |
| Neustart | R / Enter | 🔄 |
| Zum letzten Checkpoint | ⌫ Rücktaste | 📍 |
| Kamera wechseln | C | 🎥 |
| Pause | Esc | ⏸️ |

## Strecken-Editor

| Aktion | Taste |
|---|---|
| Bauteil setzen | Linksklick / Antippen |
| Teile überlappen lassen | Alt / Strg + Klick |
| Bauteil löschen | X, Shift + Klick oder ❌-Modus |
| Bauteil drehen | R / Leertaste |
| Höhe ändern | Q / E |
| Feines Raster | G |
| Testfahrt | T |
| Rückgängig / Wiederholen | Strg + Z / Strg + Y |
| Kamera bewegen | WASD, Rechtsklick ziehen, Mausrad (Handy: wischen & zoomen) |
| Bauteil wählen | Zahlen 1–0 |

Im Editor kannst du außerdem die Welt (Sommer, Winter, Wüste) und den Sonnenstand ☀️ einstellen. Bauteile dürfen sich überlappen und kombiniert werden.
